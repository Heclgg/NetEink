# NetEink · 墨水屏天气牌

一块 152×152 的三色电子墨水屏，每 15 分钟自动更新一次天气，也能当电子相框用。
硬件是自画的 ESP32-S2 板，固件用 PlatformIO + Arduino 框架。

主要功能：

- **时钟 + 天气**：352 个城市任选（默认上海），手机扫码换城市，也可以按网络定位就近选
- **电子相框**：手机扫码传图，在手机端裁切/抖动，设备只收 5.7KB 点阵；照片断电不丢
- **电池供电**：单节 3.7V 锂电，电量百分比显示在屏上

## 1. 硬件

| 项目   | 说明                                            |
|--------|-------------------------------------------------|
| 主控   | ESP32-S2（单核 240MHz，320KB RAM，无 PSRAM）    |
| Flash  | W25Q16JV，2MB                                   |
| 屏幕   | 微雪 1.54 寸 e-Paper (C)，152×152，黑/白/红三色 |
| 电池   | 单节 3.7V 锂电（500mAh），USB 供电或电池供电    |
| 指示灯 | 板载 WS2812，**默认关闭**（见 §9）              |

引脚（依据 `docs/custom_esp32s2_schematic.svg`）：

| 功能                                    | GPIO                                  |
|-----------------------------------------|---------------------------------------|
| 屏幕 SCLK / MOSI / CS / DC / RST / BUSY | 12 / 11 / 6 / 5 / 4 / 7               |
| KEY1 / KEY2                             | 1 / 2（按下为低，内部上拉）           |
| 电池检测 BAT_ADC                        | 3（ADC1_CH2，R3=100K / R4=220K 分压） |
| WS2812 数据                             | 9                                     |

> ESP32-S2 只有 2.4GHz WiFi，连不上 5GHz 热点。

## 2. 编译与烧录

需要 [PlatformIO](https://platformio.org/)。串口是 ESP32-S2 的**原生 USB CDC**（不是 CH340 那种桥），设备管理器里通常显示为
COM9。

```bash
pio run                  # 调试版：日志全开
pio run -e release       # 发布版：日志全部编译掉，Flash 小 68KB
pio run -t upload        # 烧录（默认调试版）
pio run -e release -t upload
pio device monitor       # 看串口日志，115200
```

几个容易被坑到的设置（都在 `platformio.ini`，已配好）：

- `upload_speed = 115200`：原生 USB CDC 没有真实波特率，提速会让 esptool 失步
- `board_build.flash_mode = dio`：兼容性优先，自画板不敢直接用 qio/80MHz
- `board_build.partitions = partitions.csv`：2MB 的自定义分区表（app 1.75MB）

烧录后如果串口一片空白，是 release 版的正常表现（日志被宏删干净了）。

## 3. 第一次使用：配网

1. 上电。没配过网会自动开热点，屏上显示二维码和提示"扫码配网"；
2. 用手机相机扫描屏上的二维码 —— 它会直接帮你连上热点：

   | 项目   | 值                                    |
   |--------|---------------------------------------|
   | 热点名 | `NetEink-XXXX`（XXXX = MAC 末两字节） |
   | 密码   | `12345678`                            |

3. 连上后一般会自动弹出配置页（captive portal）。没弹就手动打开 <http://192.168.4.1>；
4. 页面里选你家 WiFi、填密码、保存。保存后设备自动连接（板载灯默认关闭，进度看屏幕）；
5. 连上后设备对时、拉天气、刷屏，约 30 秒后出现第一个天气页。

凭据存在 NVS，之后掉电重启会自动重连。

## 4. 日常操作

### 4.1 按键

| 操作                    | 作用                                                                     |
|-------------------------|--------------------------------------------------------------------------|
| **短按**（任一键）      | 打开设置页：屏上显示二维码，手机扫码后可换城市                           |
| **长按 KEY1**（1.5 秒） | 打开传图页（同一个网页，扫码后传图区就在最上面）；再长按一次退出         |
| **长按 KEY2**           | 屏上是天气页时：调出上一次传的照片（不联网）<br>屏上是照片时：回到天气页 |
| 设置页/看图页里短按     | 不响应（防止误触把照片刷掉）                                             |

### 4.2 天气页

```
┌────────────────────────────┐
│ 上海                 11/22 │  ← 城市 / 日期
│         14:30              │  ← 当前时间（本地 RTC）
│ ────────────────────────── │
│  ☀        12°              │  ← 天气图标 + 当前温度
│  晴             ▭▭▭▭ 78%  │  ← 天气文字 + 电量
│ ────────────────────────── │
│ 最高 16°      最低 8°      │
└────────────────────────────┘
```

- 每 15 分钟刷新一次，对齐 `:00 / :15 / :30 / :45`；
- 刷一次全屏要约 20 秒，三色屏只能全刷，期间屏幕会闪几下是正常的；
- 刷完面板立刻 `Sleep()` 下电（POWER_OFF + VCOM 归零）——三色屏长期带电会因直流偏压让红色粒子迁移，整屏泛红，这一句不能省；
- 拉不到天气时显示"无网络"页，按任意键重试；
- 电量 ≤15% 时电池图标和数字变**红色**。

### 4.3 换城市

1. **短按**任意键 → 屏上出现"扫码设置城市"的二维码；
2. 手机扫码打开网页，城市卡片会自动展开；
3. 两种选法：
    - **搜索**：输入城市名或省份（如"苏州""江苏"），点一下即切换；
    - **用当前位置自动选**：按网络出口 IP 定位，就近匹配城市；
4. 选完设备自动停掉网页、回天气页并刷新（约 20 秒）。

城市编号存 NVS，重启后保持。城市表覆盖全部地级市 + 直辖市 + 海南 8 个县级市，共 352 个。

### 4.4 传图

1. **长按 KEY1** → 屏上出现"扫码传图"的二维码；
2. 手机扫码打开网页，往下滚到"选择照片"；
3. 选图后可以拖动、双指缩放、旋转，调对比度；
    - **抖动开**（默认）：灰阶靠点阵疏密过渡，照片更自然；
    - **抖动关**：纯黑白二值，适合二维码/线稿/文字；
    - **黑色变红**：把整层墨色换成红色；
4. 点"上传到屏幕"，屏上会刷新这张图（约 20 秒）；
5. 可以连着传多张，每张都会覆盖上一张并另存一份到 Flash。

**长按 KEY2** 可以随时把最后一张调出来，不联网、不用手机 —— 断电也不丢（8 个槽轮着写）。

### 4.5 空闲自动休眠

设备空闲 **60 秒**没有操作就进深度睡眠，待机电流降到 20µA 级别（再加上电池分压的 13µA）。

| 当前界面             | 醒来方式                                            |
|----------------------|-----------------------------------------------------|
| 天气页               | **按键** 或 **15 分钟定时**（对齐 :00/:15/:30/:45） |
| 看图页（照片在屏上） | **只等按键** —— 照片是墨水屏，断电也一直显示        |
| 设置页（二维码）     | **不休眠** —— 网页服务一睡就断，手机那边会打不开    |

几点感受上的变化：

- 深睡会丢内存，所以**每次醒来都是一次完整重启**：开机、连 WiFi、对时、拉天气、刷屏，按键后大约 30
  秒才出新画面，不是"按一下就亮"；
- 屏上原有画面不会消失（墨水屏断电保留），是刷新时才被替换；
- 待机时按任意键 = 唤醒并恢复到天气页；想看照片再长按 KEY2；
- 定时唤醒比"一直开着等"更省电，代价是每次刷新多花 3~5 秒重连 WiFi。

电池续航粗算（500mAh，15 分钟一刷）：一次循环约 25 秒联网刷新 + 60 秒操作窗口，约 3mAh/小时，**5~7 天**。想更省就把
`src/main.cpp` 里的 `IDLE_SLEEP_MS` 调小（比如 10 秒）——操作窗口占的功耗其实比刷新本身还大。

## 5. 手机网页

传图页和城市页是**同一个网页**（`http://<设备IP>/`），只是入口不同：

- 短按打开的二维码指向 `http://<IP>/#city`，城市卡片自动展开；
- 长按 KEY1 打开的二维码就是根地址 `http://<IP>/`，城市卡片默认折叠，传图区在最上面；
- 不管从哪个入口进来，两块功能都在，点城市卡片标题可以展开/收起。

网页的裁剪、缩放、三色抖动全部在手机浏览器里算完，设备只收 5776 字节的双层点阵，所以不需要 JPEG 解码器，也不占内存。

## 6. 串口日志

日志全是英文，双路输出（USB CDC + UART0）。开机大致长这样：

```
========================================
  NetEink / clock + weather
  city code: 101020100 (short press to change)
========================================
[1/5] init display ...
[2/5] connect WiFi MyHome ...
[WiFi] connected 192.168.1.23  RSSI=-52
[3/5] NTP sync ...
[NTP] now 11/22 21:30
[4/5] fetch weather ...
[HTTP] GET code 101020100
[HTTP] got 4876 bytes
[HTTP] weather clear
[HTTP] 11/22  14C  high 16  low 8  clear
[BAT] adc 1786 mV -> 3900 mV (full 3900), 100%
[5/5] draw and refresh ...
[EPD] refreshing ...
[EPD] done in 18234 ms, 921 led frames
[PLAN] next refresh in 855 s
```

常见行的意思：

| 行                                    | 含义                                      |
|---------------------------------------|-------------------------------------------|
| `[CITY] current code ...`             | 当前城市编号（`101020100` = 上海）        |
| `[CITY] switched to code ...`         | 手机改过城市                              |
| `[CITY] IP geo ... (ip-api)`          | 按 IP 定位成功，括号里是用的哪个服务      |
| `[HTTP] status 404`                   | 天气接口异常，检查城市编号                |
| `[BAT] adc ... -> ... (full ...)`     | ADC 原始值 → 电池电压（满电基准）→ 百分比 |
| `[EPD] done in ... ms`                | 一次全屏刷新耗时，正常 15~22 秒           |
| `[STORE] loaded photo #n from slot m` | 长按 KEY2 从 Flash 取图                   |

排查"板子里到底烧的是哪一版"，看 `[CITY] ...(index ... of 352)` 或 `[BAT]` 这两行在不在。

## 7. 电量

- 分压：`BAT+ -- 100K --+-- 220K -- GND`，中点接 GPIO3，`V_bat = V_adc × 1.4545`
- 采样：24 次 × 4ms 摊开取平均（约 100ms），避开 WiFi 发射时的压降；用 `analogReadMilliVolts()` 走 IDF 出厂校准
- **一点标定**：首次上电把当时的读数记为"满电"（存 NVS `bat/full`），屏上直接显示 100%；以后真充满读到更高会自动往上修正（+20mV
  滞回）
- 百分比不是库仑计，是"相对标定点的电压"，平台期（3.7~3.9V）变化会比较慢

想手动指定满电读数，改 `src/battery.cpp`：

```cpp
constexpr int kManualFullMv = 0;   // 填 3921 之类，就以这个读数为 100%
```

## 8. 常见问题

| 现象                       | 排查                                                                                                          |
|----------------------------|---------------------------------------------------------------------------------------------------------------|
| 扫码后没弹出配置页         | 手动打开 <http://192.168.4.1>；确认手机连的是 `NetEink-XXXX` 热点                                             |
| 一直连不上 WiFi            | S2 只支持 2.4GHz；确认密码正确；路由器没开 MAC 过滤                                                           |
| 屏幕显示"无网络"           | 路由能上网吗？按任意键重试，或长按 KEY1 看能否打开网页                                                        |
| 屏幕放久了发红             | 面板长期带电偏压所致。固件已改成每次刷完下电；已泛红的屏断电放几小时 + 全刷几次大多能恢复，仍不恢复属面板老化 |
| 扫码后选城市没反应         | 手机和设备必须连同一个 WiFi；看串口有没有 `[CITY] requested code ...`                                         |
| 定位总是失败               | `ip-api.com` / `ipwho.is` 在部分网络下不通，手动选城市即可                                                    |
| 传图后照片没了             | 换过 `partitions.csv` 会让槽位挪位，重传一张                                                                  |
| 电量一直 100%              | 标定锚点定低了；或插着 USB 在充电（读的是充电电压）                                                           |
| 板载灯不亮                 | 默认关闭，见 §9                                                                                               |
| 刷屏要 20 秒               | 三色墨水屏只能全刷，属正常                                                                                    |
| 按键后没反应，等一会儿才亮 | 深睡醒来是完整重启，约 30 秒；串口会先打 `[PWR] wake by key`                                                  |
| 串口隔一阵"掉线"再重连     | 深睡会断开 USB，醒来重新枚举，属正常                                                                          |
| 设置页能一直操作吗         | 能，设置页不休眠；退出回天气页后 60 秒才睡                                                                    |

## 9. 编译开关

两个总开关，都在 `platformio.ini`：

```ini
[flags]
led = -DNETEINK_LED=0          # 板载 WS2812：0 = 彻底关闭（只把 GPIO9 拉低）

[env:release]
build_flags = -DNETEINK_LOG=0  # 发布版：日志连同格式字符串一起编译掉
```

想恢复指示灯（绿/橙各闪三下），把 `led` 改成 1 即可 —— 引擎、闪三下的参数、RMT 自愈逻辑都还在 `src/rgb_led.cpp`。

|-------------------|----------------------------------------------------------------------------------------------------------------------------|
| 加中文字 / 换图标 | 改 `tools/gen_ui_assets.py` 的 `CN_CHARS` 或图标资源，重跑脚本                                                             |

> `UnicodeDecodeError`。中文说明写在 `platformio.ini` 里。

## 11. 已知限制

- **只有地级市**：县级市（昆山、义乌等）会落到最近的地级市，天气差别不大
- **不能按拼音搜城市**：中文输入；城市表里没有拼音字段
- **电量是估算**：单点电压标定，不是库仑计
- **串口日志全是英文**：城市名打成编号（`101020100`），要看中文名就看屏幕
- **一次刷新 20 秒**：三色墨水屏的物理限制，做不了局部刷新
- **浏览器定位需要 HTTPS**：`http://192.168.x.x` 不是安全上下文，手机 GPS 会被拒，实际走的是设备侧 IP 定位
